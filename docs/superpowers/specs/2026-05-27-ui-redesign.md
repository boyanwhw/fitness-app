# UI 重设计 - 极简暗色

## 设计方向

参考 Linear / Vercel 风格，极简暗色主题。靠克制取胜——没有花哨的颜色、
没有多余的装饰，用字体层级和留白制造高级感。

## 设计令牌

| 令牌 | 值 | 用途 |
|------|-----|------|
| 背景 | #0a0a0a | 页面底色 |
| 卡片 | #111111 | 卡片/区域底色 |
| 边框 | #1a1a1a | 卡片和输入框边框 |
| 主文字 | #ededed | 标题、正文 |
| 次文字 | #5c5c5c | 标签、说明文字 |
| 按钮主色 | #ededed | 主按钮背景（白底黑字） |
| 圆角 | 8px | 统一圆角 |
| 字体 | system-ui | 系统原生字体 |

## 改动范围

- `css/style.css` — 完全重写
- 所有 5 个 HTML 页面 — 样式类名微调（结构不变，只改外观）
